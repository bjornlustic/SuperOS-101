▶ Config · Clock
Changes apply to the unit immediately and are saved in its EEPROM. If the sequencer feels 4× too slow you are on 1/4; the default is 1/16. The same setting is on the panel menu as the 10 lowest keys (see the menu map below); they are the lowest ten keys counting black keys, not the white keys.
LOCKED hard-syncs the analog LFO to the clock at this musical rate, from 1/1 (a bar) up. FREE lets the LFO run at its rate knob for modulation while the sequencer stays clocked. AUTO follows the LFO RATE slider: the firmware measures the slider's rate and locks to the nearest division, so sweeping the slider steps through musical rates. Panel menu: key 14 toggles locked/free.
▶ Performance reading...
Panel: while playing, UP / DOWN / U&D, DOWN + U&D = random. Menu keys 15–18. Ping-pong repeats its end steps, so a round trip stays on the bar.
Panel: in arp mode, KEY TRANSPOSE + UP / DOWN.
With MIDI sync on, the whole machine plays this much later than the incoming clock. Menu keys 20–31.
—
PLAY + U&D randomize (rhythm + pitch) · PLAY + UP new pitches · PLAY + DOWN mutate · PLAY + KEY TRANSPOSE + key = scale root (the same key again = next scale) · PLAY + KEY TRANSPOSE tap = scale on / off. Randomized notes land in the pattern's scale.
▶ Panel menu map (on the unit itself) HOLD + KEY‑TRANSPOSE, 2 s
Enter: hold HOLD + KEY-TRANSPOSE for 2 seconds (running or at power-on). The HOLD LED marks the menu; KEY-TRANSP LED = sync on; function LED 1 = 80C49, 2 = SuperOS.

Keys 1–10 (red, lowest ten keys, black keys included) pick the clock division directly. Key 11 = MC-202 accent model · Key 12 = TB-303 accent model · Key 13 = toggle MIDI filter-cutoff CC · Key 14 = LFO locked-to-clock / free-running toggle · Keys 15–18 = sequencer direction (forward, backward, ping-pong, random) · Key 19 = pedal jack HOLD / KEY TRANSPOSE · Keys 20–31 = sync delay 0, 2, 4, 6, 8, 10, 12, 15, 18, 21, 25, 30 ms. The accent model and CC toggle are panel-menu only; channel, sync, divide, the LFO lock, direction, pedal and sync delay can also be set from this page.
▶ Log
SysEx F0 7D <cmd> ... F7. With Edit live on, notes go to the unit as 0x18 length + 0x16 set-step deltas (or one 0x12 pattern write for big changes); the unit flushes to flash about half a second after the last change. Patterns recorded or selected on the unit appear here automatically.
