Introduction
1

About superOS-101

superOS-101 is custom firmware for a drop-in replacement of the Roland SH-101's original CPU, a Toshiba TMP80C49. Unlike the TB-303, TR-606, and TR-808, which share the NEC µPD650 and therefore share one replacement board, the SH-101 needs its own CPU board and its own firmware, designed from a clean sheet.

The firmware reproduces the original CPU's electrical behavior exactly: the DAC and multiplexer protocol that generates every control voltage in the synth, the keyboard and panel scan, and the gate, clock-reset, and portamento signals. On top of that foundation it re-implements the SH-101's musical features, keyboard, arpeggiator, and 100-step sequencer, against the fully disassembled original ROM as reference.

The Combined Edition holds two complete operating systems in one chip: superOS-101 and 80C49 mode, an emulation of the original SH-101 CPU running the genuine Roland mask ROM. You can switch between them from the panel at any time. See the Combined Edition chapter.

2

How to Use This Manual

Panel Names

Controls are written as they appear on the panel: the function buttons LOAD PLAY DOWN UP&DOWN UP HOLD KEY TRANSPOSE, the RANGE switch (16′ / 8′ / 4′ / 2′), the TRANSPOSE switch (octave down / middle / up), and the envelope TRIG switch (GATE / GATE+TRIG / LFO). The keyboard has 32 keys, F to high C.

A combination such as HOLD + KEY TRANSPOSE means: hold both controls at the same time.

Note All sequencer and arpeggiator clocking comes from the LFO or the EXT CLK jack, exactly as on the original instrument. Where this manual says "each clock pulse," that is the source it means.
Playing
1

The Keyboard

The keyboard plays monophonically over its 32-key range, with the pitch CV following the original's confirmed 1 V/octave numeric model, so tuning and scaling match a stock SH-101 exactly.

Note Priority

When more than one key is held, the envelope TRIG switch selects which note sounds, as on the original:

  • GATE or LFO: lowest-note priority. The lowest held key sounds.
  • GATE+TRIG: last-note priority. The most recently pressed key sounds; releasing it falls back to the lowest key still held.

In the LFO position the LFO is restarted on each new key press, so an LFO-triggered envelope always starts its cycle in step with your playing.

3

The Arpeggiator

Press UP, DOWN, or UP&DOWN to turn the arpeggiator on in that direction; press the same button again to return to normal keyboard play. Hold any group of keys and the arpeggiator steps through them, one note per clock pulse, at the rate set by the LFO (or the EXT CLK input).

  • UP: lowest to highest, then wraps to the lowest.
  • DOWN: highest to lowest, then wraps to the highest.
  • UP&DOWN: bounces between the lowest and highest held keys.

Keys can be added or released while running; the pattern follows the currently held set. The gate closes when all keys are released.

The Sequencer
1

Recording a Sequence

Press LOAD to start recording into the current pattern slot (the LOAD LED lights). The slot is cleared and every key you press is appended as the next step, up to 128 steps. The keyboard sounds while you record, so you hear each note as you enter it. Notes arriving over MIDI record too.

ControlWrites
Keyboard keyA note step at that pitch (TRANSPOSE applies as played).
KEY TRANSPOSEA rest step.
Hold HOLD + keyA legato step: this note starts without the gate dropping, so the envelope does not retrigger and, with PORTAMENTO on AUTO, it glides.
LOAD againEnds recording; the pattern is saved to permanent memory automatically.
2

Playing a Sequence

Press PLAY to start the sequencer; press it again to stop and return to keyboard play. Steps advance one per clock pulse (the LFO/EXT CLK, or MIDI clock when sync is on): note steps retrigger the gate at their pitch, rest steps close the gate, and legato steps change pitch with the gate held. At the end of the pattern playback wraps to the first step.

3

Patterns: Selecting, Loading and Saving

There are eight pattern slots, and saving is automatic. To choose a slot, hold PLAY and press one of the eight lowest keys: F3 selects pattern 1, F♯3 pattern 2, and so on up to C4 for pattern 8. The new pattern becomes the current one, for playing and for recording, and the sequencer keeps running if it was running.

ToDo
Load (select) pattern 1…8Hold PLAY, press key F3…C4 (the eight lowest keys). Also MIDI Program Change 0…7, or the web editor.
Record into the current slotLOAD, play the steps, LOAD again (see Recording a Sequence).
SaveNothing to press: about half a second after you finish an edit, the pattern is written to the CPU's permanent flash memory.
Move a pattern to another slotSelect the target slot, then record it there, or copy it in the web editor (read, choose the slot, write).
Keep patterns off the unitThe web editor (over USB-C or DIN MIDI) reads and writes all eight slots and saves them as a JSON file.

Patterns survive power-off with no battery, an upgrade over the original's battery-backed RAM: no battery to replace and nothing to lose when it runs down. Slot selection is ignored while recording, so finish with LOAD first, then move to another slot. Firmware updates over MIDI never touch the pattern memory.

MIDI
1

MIDI Clock Sync

With MIDI clock sync on, incoming MIDI clock replaces the LFO / EXT CLK as the instrument's musical clock, divided to a rhythm you choose. Three things lock to the beat:

  • The arpeggiator and sequencer advance one step per division, exactly in time with your DAW. MIDI Start (and Stop) are honored: Start rewinds the sequence and the arpeggio to the downbeat, Stop freezes them.
  • The LFO triangle and square are hard-synced: the LFO restarts on every division boundary. The RATE knob still sets the slope between restarts, so set it near the division rate for a clean locked wobble, or far off it for truncated hard-sync shapes.
  • The random (S&H) waveform steps to a new value once per division instead of free-running.

Divisions

Ten divisions, all exact at MIDI's 24 pulses per quarter (no drift): 1/4, 1/4 dotted, 1/4 triplet, 1/8, 1/8 dotted, 1/8 triplet, 1/16, 1/16 dotted, 1/16 triplet, 1/32. They are selected in the Config Menu (see Combined Edition): UP&DOWN toggles sync, UP / DOWN cycle the division, and the ten lowest keyboard keys select it directly, lowest key = 1/4 rising chromatically to 1/32. Both settings are remembered across power-off.

Note MIDI arrives through the panel MIDI breakout. While sync is on and the transport is stopped (or no clock is arriving), the arpeggiator and sequencer wait; turn sync off to clock from the LFO again. The noise LFO waveform is analog and cannot be synced. MIDI notes play the synth and its own notes are echoed on MIDI OUT: see “Playing over MIDI” above.
Combined Edition
1

Two Firmwares in One Chip

Like the superOS-303 Combined Edition, one image carries two complete firmwares, with one active per boot:

  • superOS-101: the firmware described in this manual.
  • 80C49 mode: an emulation of the original SH-101 CPU running the genuine Roland mask ROM, for a bone-stock instrument.

The selection is remembered across power-off; the unit always boots into whichever firmware you last chose. Switching is done from the Config Menu and takes effect through an immediate reboot, about as fast as flipping the power switch.

2

The Config Menu

Hold HOLD + KEY TRANSPOSE for 2 seconds, in either firmware, while playing or idle. You can also hold the combination while switching the power on. In the menu the HOLD LED lights, the gate is forced off, and the function LED shows which firmware is currently running: LOAD lit = 80C49 mode, PLAY lit = superOS-101.

Note If no mask ROM is installed in the build, LOAD does nothing and the unit always boots superOS-101. See 80C49 Mode below.
3

80C49 Mode

In 80C49 mode the unit runs the original SH-101 program, byte for byte. The emulated CPU's ports are wired straight through to the synth, so the original's own scan patterns, DAC writes, and timing loops drive the analog board unchanged: every behavior of a 1982 unit is reproduced, including its quirks. For the workflow in this mode, the original Roland SH-101 owner's manual is the manual.

  • The keyboard, arpeggiator, sequencer, hold, and key transpose all behave exactly as stock.
  • The original service Test Mode works: hold LOAD + KEY TRANSPOSE while switching the power on (see the Roland service manual for the test procedures).
  • The superOS Config Menu combo (HOLD + KEY TRANSPOSE, 2 s) still works, so you can always switch back.
  • MIDI clock sync works here too: with sync on, the divided MIDI clock is fed to the original program in place of the LFO / EXT CLK, so even the stock arpeggiator and sequencer run DAW-locked at the chosen division.
  • MIDI notes work here too: notes 53…84 (F3…C6, the SH-101's own keys) are pressed into the emulated key matrix, so the original program sees them as keys and they arpeggiate, record and transpose like keys. Notes outside that range have no key and are ignored. Whatever the original program plays is echoed on MIDI OUT.

Sequence Memory in 80C49 Mode

The original CPU kept its sequence in battery-backed internal RAM. In 80C49 mode that RAM region (the 100 sequencer steps) is mirrored to the CPU's permanent memory: about a second after you finish recording it is saved, and it is restored before the original program starts, so the sequence survives power-off with no battery, exactly as a healthy stock unit would keep it. superOS-101's own eight patterns are separate and unaffected.

The Mask ROM

The original ROM is Roland's copyrighted code and is never distributed with superOS-101. It is embedded at build time from your own dump of an SH-101's 2 KB ROM. A build made without a dump still works fully as superOS-101; only 80C49 mode is unavailable.

Note The emulator is paced to the original's 6 MHz clock. On the current CPU board the emulated program may run somewhat below full speed; pitch CVs and clock-driven tempo are unaffected (the arpeggiator and sequencer follow the LFO / EXT CLK), but key-scan response can be slightly slower than a stock unit. This is being measured during board bring-up.
Reference
1

Installing & Updating

During bring-up the firmware is flashed over USB with the Teensy loader (the CPU carries the HalfKay bootloader), or over the board's ISP header. A MIDI SysEx updater like the superOS-303's, so the firmware can be updated with no tools through the MIDI breakout, is planned for the production release.

Warning Do not disconnect power while a firmware update is in progress unless the update has failed.
2

Development Status

v0.1-alpha is bring-up firmware: the CV/gate core, panel decode, keyboard, arpeggiator, sequencer, Config Menu, and 80C49 mode are implemented and verified against a pin-level simulation of the synth. Not yet implemented:

  • KEY TRANSPOSE in superOS-101 (works in 80C49 mode).
  • HOLD latch of keys and arpeggios in superOS-101 (the button currently writes ties while recording; hold works fully in 80C49 mode).
  • Exact portamento and clock-reset timing fidelity.

MIDI notes in/out are implemented, in both firmwares; an earlier edition of this manual said otherwise and was wrong. Notes 53…84 play the keyboard, notes outside that range play as a mono override, and the synth’s own note and gate are echoed on MIDI OUT. Confirmed on hardware.

Specifications

  • CPU AT90USB1286 (16 MHz) on a drop-in board for the SH-101's 40-pin 80C49 socket. USB for firmware flashing; MIDI via the panel breakout (hardware present, firmware planned).
  • CV engine Bit-faithful reproduction of the original DAC/multiplexer protocol: 6-bit pitch, range, and random CVs into the original sample/holds, with the original's scan-safety guarantees. Confirmed 1 V/octave numeric model.
  • Keyboard 32 keys, monophonic, lowest- or last-note priority (TRIG-switch selected), octave TRANSPOSE, RANGE 16′–2′.
  • Arpeggiator Up, down, up&down over held keys; clocked by LFO or EXT CLK.
  • Sequencer 8 patterns of up to 128 steps of note / rest / legato, clocked by LFO, EXT CLK, or divided MIDI clock, saved automatically to permanent on-chip memory (no battery).
  • MIDI clock sync 24-ppqn realtime clock with Start / Stop / Continue; ten drift-free divisions (1/4 … 1/32 with dotted and triplet); clocks the arp/sequencer, hard-syncs the analog LFO via CLOCK RESET, and steps the random S&H; works in both firmwares (injected on the emulated T1 in 80C49 mode). Settings retained across power-off.
  • 80C49 mode Full-ISA MCS-48 emulation of the original CPU running the genuine mask ROM (user-supplied, never distributed), ports passed 1:1 to the synth, paced to the original 6 MHz clock.
  • Firmware select Panel Config Menu (HOLD + KEY TRANSPOSE, 2 s or at power-on); choice retained across power-off.
